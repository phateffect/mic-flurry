# MicFlurry 安装说明（朋友测试版）

这个压缩包会把 MicFlurry 虚拟麦克风完整装到你的 Mac 上：音频驱动 + 后台服务，一步装完。

## 要求

- Apple Silicon 芯片的 Mac(M1/M2/M3/M4 系列）
- macOS 15 或更新版本

## 安装

1. 解压 zip，得到 `MicFlurry-friend-版本号` 文件夹。**不要只拖出其中一两个文件，整个文件夹保持原样。**
2. 双击文件夹里的 `Install MicFlurry.command`。
   - 如果 macOS 提示"无法打开，因为无法验证开发者"：打开 **系统设置 → 隐私与安全性**，在下方找到 MicFlurry 相关提示，点 **仍要打开**，然后再次双击。
   - 不要右键"打开"之外的任何绕过方式，也**不要**关闭 Gatekeeper。
3. 安装过程中会弹出一次系统密码框（安装到系统目录需要管理员权限），输入你的开机密码。
4. 安装快结束时，macOS 可能依次请求这些权限，请全部允许：
   - **输入监控**(Input Monitoring)：给 `/Applications/MicFlurry.app`，用于接管遥控器按键
   - **蓝牙**：用于连接遥控器
   - **辅助功能**(Accessibility)：用于模拟按键
5. 装完后重新打开要用麦克风的应用（腾讯会议、飞书、微信等），在麦克风列表里选择 **MicFlurry**。

## 使用

- 把小米遥控器通过系统蓝牙配对连接，后台服务会自动接管。
- 其他应用从 `MicFlurry` 这个麦克风拿到的就是遥控器语音。

## 卸载

双击文件夹里的 `Uninstall MicFlurry.command`，输入一次密码即可。会删除驱动和后台服务；
你的录音文件和个人数据不会被动。
